# Lagari Group (Pty) Ltd

**Practical IT support for growing South African businesses.**

Lagari Group is an IT consulting firm based in Centurion, Gauteng. We help SMEs and startups choose the right technology, build software, run cloud workflows securely, and keep daily operations running, with tailored support and without enterprise-level overhead.

> We don't build technology for technology's sake.

## What we do

- **IT consulting and planning**: roadmaps, audits, and vendor reviews
- **Custom software and integrations**: internal tools, APIs, and workflow automation
- **Cloud services and architecture**: Azure, AWS, and GCP, including backups and cost control
- **Microsoft 365 and SharePoint**: setup and hardening
- **Cybersecurity fundamentals**: MFA, endpoint protection, email authentication (SPF/DKIM/DMARC), and incident hygiene
- **Managed IT support**: helpdesk, hardware lifecycle support, and vendor liaison
- **AI and workflow automation**: n8n, Power Automate, and Python
- **Websites and digital platforms**: built with Next.js and React
